# 🌐 Guide: 24/7 Free Hosting & Secure Free Database

This guide explains how to host your **FastAPI Backend** and **React Frontend** 24/7 for free (without sleeping) and set up a **secure MongoDB database** at zero cost.

---

## 💾 Part 1: Secure & Free MongoDB Database (MongoDB Atlas)

To replace your local MongoDB (`mongodb://localhost:27017`), you should use **MongoDB Atlas**. They offer a **free forever (M0 Sandbox) cluster** which is fully managed and secure.

### Step-by-Step Setup:
1. **Sign Up:**
   - Go to [MongoDB Atlas](https://www.mongodb.com/cloud/atlas/register) and create a free account.
2. **Create a Free Cluster:**
   - Choose the **M0 Free** tier.
   - Select your preferred cloud provider (e.g., AWS) and region closest to you.
   - Click **Create**.
3. **Configure Security:**
   - **Database User:** Create a username and a strong password. Save these credentials!
   - **IP Access List (Network Access):** 
     - Add IP `0.0.0.0/0` (allows access from any hosting provider like Render or Vercel).
     - *Note: This is secure because users still need your database username & password to connect.*
4. **Get your Connection String:**
   - Click **Connect** -> **Drivers** -> **Python**.
   - Copy the connection string. It will look like this:
     ```env
     mongodb+srv://<username>:<password>@cluster0.xxxxxx.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0
     ```
   - Replace `<username>` and `<password>` with the credentials you created.
5. **Update Backend Config:**
   - Update your backend `.env` file:
     ```env
     MONGO_URL="mongodb+srv://<username>:<password>@cluster0.xxxxxx.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0"
     DB_NAME="bugzx_database"
     ```

## 🚀 Part 2: Deploying FastAPI Backend 24/7 for Free

Most free backend platforms (like Render or Koyeb) spin down or "sleep" your web service after 15 minutes of inactivity. We can bypass this by using Render combined with a **free ping service** to keep it awake 24/7.

### Option A: Render (FastAPI + Keep-Awake Ping) — *Recommended*

**Render** allows you to host web servers for free.

#### 1. Prepare your backend repository:
Create a `Dockerfile` in your `backend` folder to ensure it runs correctly on Render:
```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "server:app", "--host", "0.0.0.0", "--port", "8000"]
```

#### 2. Deploy on Render:
1. Push your code to GitHub (keep the repo private to protect credentials).
2. Sign in to [Render](https://render.com) using your GitHub account.
3. Click **New +** -> **Web Service**.
4. Connect your GitHub repository.
5. Configure the service:
   - **Name:** `bugzx-backend`
   - **Environment:** `Docker` (or Python if you prefer not to use Docker)
   - **Region:** Choose the region closest to your MongoDB Atlas cluster.
   - **Branch:** `main` (or your active development branch)
   - **Root Directory:** `backend` (if your FastAPI code is inside a subfolder)
   - **Instance Type:** `Free`
6. Add Environment Variables (click **Advanced** -> **Add Environment Variable**):
   - `MONGO_URL` = *Your MongoDB Atlas connection string*
   - `DB_NAME` = `bugzx_database`
   - `CORS_ORIGINS` = `https://your-frontend-domain.web.app` (your frontend deployment URL)
7. Click **Create Web Service**. Render will build and deploy your backend.

#### 3. Keep it awake 24/7 (Preventing Sleep):
To prevent Render from putting your app to sleep, setup a ping service:
1. Go to [Cron-Job.org](https://cron-job.org/) or [UptimeRobot](https://uptimerobot.com/) and register a free account.
2. Create a new **cron job** or **monitor**:
   - **URL:** `https://your-backend-render-url.onrender.com/api/` (or whichever endpoint returns a health status)
   - **Interval:** Every **14 minutes** (Render sleeps after 15 minutes of inactivity).
3. This will ping your app every 14 minutes, keeping it active 24/7.

### Option B: Hugging Face Spaces (Docker-based, Free 24/7)

Hugging Face Spaces allows you to host Docker apps for free. They also sleep after 48 hours of inactivity, but can be kept awake indefinitely using the same **Cron-Job.org** ping method.

1. Go to [Hugging Face](https://huggingface.co/) and create a free account.
2. Click **New** -> **Space**.
3. Choose **Docker** as the SDK, and select **Blank** template.
4. Set the space to **Public** (or Private) and create it.
5. Upload your backend folder files (including the `Dockerfile` shown above) to the space.
6. Under Settings, add your environment variables (`MONGO_URL`, `DB_NAME`, etc.).
7. Setup **Cron-Job.org** to ping your Space's direct app URL every 10–15 minutes.

## 🔒 Security Best Practices for Production

1. **Never Commit Secrets:** Do not hardcode your MongoDB credentials or production environment variables into your Git repository. Always use `.env` files locally (added to `.gitignore`) and set environment variables directly in the Render/Firebase console.
2. **Restrict CORS:** Set `CORS_ORIGINS` in your backend configuration to strictly match your deployed frontend URL. This prevents other websites from making unauthorized requests to your API.
3. **Database Backups:** MongoDB Atlas free tier provides robust security but doesn't include automated backups on the free tier. Ensure you occasionally export critical data if necessary.
